## Fonts

- **No font file is bundled yet.** The UI uses the player's operating-system font through Godot's `SystemFont` (Bahnschrift on Windows 10/11, falling back to Segoe UI or Arial). Nothing is redistributed.
- To ship a font with the game, add an open-licence font (for example *Rajdhani*, SIL Open Font License 1.1) as `assets/fonts/Rajdhani-SemiBold.ttf`. `scripts/ui/ui_style.gd` picks it up automatically. Record it here with its licence.

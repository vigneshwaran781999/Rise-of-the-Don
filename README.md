# RISE OF THE DON

*THE CITY NEVER FORGIVES.*

An original 3D open-world action-adventure set in **Velanagar**, a fictional South Indian coastal city. Built with Godot 4 (GDScript only), with placeholder 3D art generated by Blender scripts.

**Status: Milestone 1 (playable prototype).** Main menu → New Game drops you into a test city block where you can walk, run, sprint and jump with a third-person camera. See [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) for the full design and milestone plan.

## Requirements

| Tool | Version | Needed for |
|---|---|---|
| Godot | 4.7.2 stable (standard or .NET build; the project uses no C#) | Opening and running the game |
| Blender | 4.0 or newer | Only to regenerate the 3D assets (the GLBs are already in the repo) |

## Open and run

1. Start the Godot editor and choose **Import**, then select this folder's `project.godot`.
2. Press **F5** (or the ▶ Play button). The game starts at the main menu.

From the command line (Git Bash), without opening the editor:

```bash
GODOT="/c/Users/ADMIN/Downloads/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64.exe"
"$GODOT" --path .
```

The window opens at 1600×900; the game renders at a 1920×1080 base resolution and scales to the window.

## Controls

| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Walk (hold) | Ctrl | Tilt the left stick gently |
| Sprint (hold, uses stamina) | Shift | Left stick click |
| Jump | Space | A |
| Pause menu | Esc | Start |
| FPS counter | F3 | — |
| Menus: move / select / back | Arrow keys / Enter / Esc | D-pad / A / B |

Also bound for later milestones (they do nothing yet): **F / Y** enter or exit vehicle (M2), **E / X** interact.

If the mouse stops controlling the camera (for example after Alt+Tab), click in the game window.

## Settings

Main menu → Settings (or pause → Settings): master, music and effects volume, mouse sensitivity, invert look. Changes apply immediately and are saved to `%APPDATA%\Godot\app_userdata\Rise of the Don\settings.cfg` when you leave the screen.

## Project layout

```
scenes/      main/ (main menu, game), player/, world/ (test block), ui/ (HUD, pause menu)
scripts/     player/, world/, ui/, systems/ (Settings and AudioManager autoloads, game session)
resources/   tunables: characters/ (player movement and camera), world/ (lighting preset)
assets/      models/ (generated GLBs: road/, buildings/, props/, test/)
shaders/     menu background
tests/       smoke test, screenshot tool
tools/       blender/ (asset generators), godot/ (project setup script)
docs/        GAME_DESIGN.md
```

Tuning lives in resources, not code: edit `resources/characters/player_tuning.tres` (speeds, jump, stamina), `player_camera.tres` (distance, sensitivity, smoothing) or `resources/world/late_afternoon.tres` (sun, sky, fog) in the Godot inspector.

## Regenerating assets

All 3D models come from Python scripts in `tools/blender/`. To rebuild every model and re-import:

```bash
bash tools/blender/build_all.sh
```

Each generator can also be run alone and accepts asset names, e.g.
`"$BLENDER" --background --factory-startup --python tools/blender/buildings.py -- bld_shophouse_02`.
The scripts are deterministic: re-running produces identical files.

The input map, autoloads and audio buses are generated by `tools/godot/setup_project.gd`. Edit that script rather than the `[input]` section of `project.godot`, then run:

```bash
"$GODOT_CONSOLE" --headless --path . --script res://tools/godot/setup_project.gd
```

(`$GODOT_CONSOLE` is the `_console.exe` next to the editor executable.)

## Tests

```bash
# Headless smoke test: menu -> game -> movement, jump, kerbs, ramps, camera, HUD, pause -> menu
"$GODOT_CONSOLE" --headless --path . res://tests/smoke_test.tscn      # prints SMOKE TEST PASSED, exit code 0

# Visual check: renders a scene in a window, saves a PNG and prints FPS / draw calls
"$GODOT_CONSOLE" --path . res://tests/screenshot.tscn -- --scene=res://scenes/main/game.tscn --out=C:/temp/shot.png
```
